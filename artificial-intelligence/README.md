# Artificial Intelligence Projects

This folder contains laboratory work and the final exam developed during the **Artificial Intelligence** course in the third year of my Computer Science degree.

## Course Overview

The course covers fundamental Artificial Intelligence techniques, combining theoretical concepts with practical implementation using Python and Jupyter notebooks.

Topics include search algorithms, decision processes, machine learning and reinforcement learning.

## Contents

### Laboratories

The laboratory activities focus on implementing core AI algorithms:

- **Uninformed Search**
  - Breadth-First Search (BFS)
  - Depth-First Search (DFS)
  - state space exploration

- **Informed Search**
  - heuristic-based search strategies
  - cost optimization approaches

- **Markov Decision Processes (MDP)**
  - decision-making under uncertainty
  - value-based reasoning

- **Machine Learning & Reinforcement Learning**
  - basic ML concepts
  - reinforcement learning logic
  - model-based experimentation

### Final Exam

The final exam consists of a practical implementation that integrates multiple AI concepts studied during the course.

The objective is to demonstrate the ability to:

- model problems using AI techniques
- apply search or learning algorithms
- implement solutions in Python
- analyze results and performance
